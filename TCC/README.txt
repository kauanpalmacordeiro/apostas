COMO ABRIR AGORA
----------------
Abra a pasta TCC no VS Code e execute tcc.html com Live Server.
A página TCC funciona de forma independente.

CAMINHOS INTERNOS
-----------------
CSS:        ./tcc.css
JavaScript: ./tcc.js
Imagem:     ./assets/images/lamborghini-revuelto.jpg

ESTRUTURA RECOMENDADA QUANDO VOCÊ JUNTAR AS 3 TELAS
---------------------------------------------------
PROJETO/
├── INICIO/
│   ├── index.html
│   ├── style.css
│   └── script.js
│
├── TCC/
│   ├── tcc.html
│   ├── tcc.css
│   ├── tcc.js
│   └── assets/
│       └── images/
│           └── lamborghini-revuelto.jpg
│
└── JOGAR/
    ├── jogar.html
    ├── jogar.css
    ├── jogar.js
    └── assets/

O tcc.html deste pacote já aponta os botões do simulador para:
../JOGAR/jogar.html

Portanto, quando existir uma pasta JOGAR ao lado da pasta TCC, os links estarão prontos.
Se você preferir outra estrutura final, basta alterar esses hrefs.
